# Paradise Nursery Shopping Application

## Project Name
Paradise Nursery

## Description
Paradise Nursery is an online plant shopping application where users can browse different categories of houseplants, view plant details, add plants to their shopping cart, and manage cart quantities.

## Features
- Paradise Nursery landing page
- About Us section
- Plant categories
- Product thumbnails, names and prices
- Add to Cart functionality
- Dynamic cart item count
- Increase and decrease quantity
- Delete products from cart
- Total price calculation
- Checkout message
- Continue Shopping functionality

## Technologies Used
- React
- Redux Toolkit
- React Router
- JavaScript
- CSS
- Vite
